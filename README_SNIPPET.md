## Codex + Astra + DeepSeek agent setup

Astra medium plans, integrates and verifies. Separate DeepSeek Flash processes
handle bounded research, implementation and writing. Astra high reviews only when
risk justifies the extra work.

See [installation](docs/INSTALL-CODEX-ASTRA-DEEPSEEK.md) and the
[Thai quick start](README.md). This is a configurable workflow, not a promise of
lower cost for every task. Never commit API keys.
